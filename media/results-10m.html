NGINX and Envoy are userspace proxies. Every packet crosses recvfrom/sendto, a kernel/userspace copy, and real per-flow session state before it reaches their code. ringzero's XDP program runs before any of that exists, no socket, no sk_buff. That's the entire gap in the chart below, not a verdict on which proxy is better: NGINX and Envoy do TLS termination, HTTP routing, health checks, and observability that ringzero has none of, and this test gives them no credit for any of it. HAProxy isn't in the chart because it has no generic UDP passthrough, only QUIC/HTTP-3 termination, which a raw UDP flood can't exercise.
